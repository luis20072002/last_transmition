# Catálogo de mensajes de error

| Archivo defectuoso | Mensaje que ve la escritora | ¿Sabría qué corregir? (sí/no) |
|---|---|---|
| `destino_inexistente.json` | Escena 'A', opción 'o': el destino 'E99' no existe. | |
| `escena_duplicada.json` | Escena 'B': el ID está repetido. | |
| `final_con_opciones.json` | Escena 'B': es una escena final y no debe tener opciones. | |
| `ilegible.json` | El archivo no es un JSON válido (línea 1, columna 3). | |
| `inicio_inexistente.json` | El campo 'inicio' apunta a la escena 'Z', que no existe. | |
| `no_final_sin_opciones.json` | Escena 'A': no es final y debe tener al menos una opción. | |
| `opcion_duplicada.json` | Escena 'A': el ID de opción 'o' está repetido. | |
| `raiz_lista.json` | El archivo debe contener un objeto JSON en su raíz. | |
| `sin_inicio.json` | Falta el campo obligatorio 'inicio' de la historia. | |
| `valor_no_booleano.json` | Escena 'A', opción 'o': el valor de 'x' en 'condiciones' debe ser verdadero o falso, no 'si'. | |
| `variable_no_declarada.json` | Escena 'A', opción 'o': la variable 'y' en 'efectos' no está declarada. | |
